# STACKUP HOLD'EM ENDURANCE

Produto flagship da STACKUP HOLD'EM voltado para performance mental no poker.

## Direção visual

- luxo editorial / private club / high-performance lab
- carvão, nogueira escura, bronze envelhecido e marfim
- fotografia de ambiente de poker desfocada por trás da interface
- tipografia serifada para autoridade editorial + sans para UI
- menos cards decorativos, mais hierarquia, respiro e superfícies profundas

## Navegação principal

- HOME
- SESSION
- TRAIN
- COACH
- PROFILE
- SOS TILT global e persistente
