# Privacy Policy — STACKUP HOLD'EM ENDURANCE

Last updated: October 5, 2026

STACKUP HOLD'EM ENDURANCE is a poker performance and mental-training application.

## Information handled by the current app
The current version does not require an account or login.

The app allows users to interact with preparation, session, post-session, diary and cognitive-training interfaces. In the current production code, these entries are processed locally in the application and are not transmitted to a STACKUP backend.

The selected interface language is stored locally on the user's device so the preference can be restored.

## Network access
The current version may access the internet to load visual background media hosted by Pexels. When a device requests content from a third-party host, that provider may receive ordinary technical request information such as IP address and request metadata according to its own practices.

## Analytics and advertising
The audited current version does not include an application analytics SDK or advertising SDK.

## Data sharing
The audited current version does not implement transmission of diary, session, profile or training responses to a STACKUP server.

## Data retention and deletion
The language preference is stored locally on the device. Current session and diary interface values are held in application state and are not implemented as cloud records in the audited version. Removing local application data or uninstalling the app removes app-controlled local storage.

## Future changes
If future versions add accounts, cloud synchronization, analytics, crash reporting, subscriptions, advertising, messaging, AI services or other remote processing, this policy and the Google Play Data safety declaration must be reviewed before that version is released.
